# 공식 스킬 작성 지침 요약

이 문서는 공식 지침을 이 저장소의 스킬 작성에 맞춰 정리한 한국어 요약이다. 전체 원문이나
특정 모델에서의 효과를 입증한 실험 결과를 대신하지 않는다.

- [Agent Skills 규격](https://agentskills.io/specification): 필수 frontmatter, 이름·설명 제약,
  선택 필드와 파일 구조를 확인한다.
- [Agent Skills 작성 지침](https://agentskills.io/skill-creation/best-practices): 도메인 지식,
  절차, 필요한 제약과 실제 실행을 중심으로 내용을 선택한다.
- [Anthropic 스킬 작성 지침](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/best-practices):
  설명 작성, 단계별 자료 로딩, 도구와 평가 예시를 확인한다.

## 내용의 범위

역할과 적용 시점을 짧게 설명하고, 에이전트가 모를 만한 프로젝트·도메인 지식에 집중한다.
여러 올바른 방법이 있으면 기본 접근과 판단 기준을 준다. 명령·플래그·쿼리 문법처럼 에이전트가
이미 알거나 도구 오류를 보고 고칠 수 있는 내용은 쓰지 않는다.

본문에는 매번 필요한 절차를 둔다. 세부 API 자료와 긴 예시는 해당 상황에서 읽을 파일로
연결한다. 참조는 본문에서 바로 도달하도록 구성하고 읽을 조건을 밝힌다. 이름과 설명에는
관련 작업을 찾는 데 필요한 용어를 쓰며, 본문에는 그 작업을 수행하는 방법을 쓴다.

## 예시와 도구

같은 패턴을 반복하기보다 실제 입력과 기대 결과가 보이는 예시를 선택한다. 스크립트는 외부 도구로
얻을 수 없는 계산·검증에만 두고 의존성·입출력·실패 시 확인 방법을 설명한다. 민감하거나 파괴적인
작업은 실제 대상과 실행할 내용을 확인할 수 있는 중간 산출물과 검증 단계를 둔다.

## 평가

실제 작업으로 지침의 적용과 결과를 확인하고, 불필요한 호출·빠진 조건·혼동한 부분을 수정한다.
실행하지 않은 모델·환경까지 효과를 확대하지 않는다. 형식·설치 검증과 작업 수행 결과는
서로 다른 근거로 기록한다.
